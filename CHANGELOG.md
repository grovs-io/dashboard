# Changelog

All notable changes to the Grovs dashboard are documented here. Versions follow
[semantic versioning](https://semver.org/) and match the backend; the matching
image is `ghcr.io/grovs-io/dashboard:<version>`.

## [3.0.0] - 2026-10-26

### Upgrade notes

- Requires backend 3.0.0: the new screens call endpoints that older backends do
  not have.
- Set `TRUSTED_PROXY_SECRET` to the same value as the backend so login and SSO
  requests carry the end user's IP (generated by the self-host setup script).
- `Dockerfile.selfhosted` now builds the core edition unless
  `NEXT_PUBLIC_GROVS_EE=true` is passed.

### Added — Enterprise Edition (`ee/`)

- **Segments**: audience builder with live reach, members, breakdowns, size
  history and exports.
- **Push campaigns**: composer, targeting, scheduling, holdouts and delivery
  reports.
- **In-app messages**: templates, surveys and custom HTML with a live preview,
  a template gallery, targeting and reports.
- **Journeys**: visual multi-step flows with A/B paths and conversion goals.
- **Event streaming**: destinations, exports and tokens.
- **Engagement Settings** for push and in-app defaults.

### Added — core

- Guided project setup: link domain, connecting each platform, first links and a
  live test, with progress saved as you go.
- Built-in Home dashboards and custom dashboards built from any metric, filter
  and breakdown.
- Analytics overview filters, breakdowns and a unified metric query.
- Smart banners.
- In-app browser handling settings for link previews.
- Project icons from the App Store and Google Play.

### Changed

- Many UI fixes across links, domains, analytics and settings.

### Security

- `next` 16.4.3, `axios` 1.20.0, `sharp` 0.35.5, `zod` 4.6.7, and patched
  `dompurify`, `follow-redirects`, `undici`, `vite`, `source-map-js` and `fflate`,
  clearing every high and critical npm advisory.

### License

- The root `LICENSE` now states that `ee/` is governed by `ee/LICENSE` and that
  everything else is MIT, matching the backend. `package.json` points to it.
